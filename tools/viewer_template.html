How these numbers are calculated
  • Baseline subtraction. For each well, a straight line is fitted to the RFU values over the baseline cycles and subtracted from the whole curve, so every curve starts near zero. Pick baseline cycles that come before any well starts to rise.
  • Threshold. The Auto threshold is 10× the average standard deviation of the baseline-subtracted RFU in the baseline cycles, taken across every well with data (the same rule CFX Maestro uses by default). Drag the dashed line or type a value to set your own.
  • Cq (quantification cycle) is the fractional cycle where the baseline-subtracted curve last crosses the threshold on its way up, found by linear interpolation between the two cycles on either side. Wells that never stay above the threshold get no Cq (—).
  • Melt peak. −d(RFU)/dT is computed with a 5-point Savitzky–Golay derivative, which smooths as it differentiates. Peaks taller than the peak threshold, and standing clearly above the valleys on either side, are reported; the tallest gives the Tm. Extra peaks (shown as % of the main peak height) can mean primer dimers or a non-specific product.
  • Values come from this page's own analysis and can differ slightly from CFX Maestro, which also applies its own dye calibration and curve fitting.
