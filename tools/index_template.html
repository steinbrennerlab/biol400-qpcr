About this page
  • Click a run to open its viewer: pick wells on the plate map and look at amplification curves, melt curves and melt peaks with their Cq and Tm values. Each viewer page works offline once saved (File → Save page as).
  • Download Cq & Tm makes one CSV for every run currently shown, using each run's default settings (baseline cycles 3–15, auto threshold, auto peak threshold). To use your own threshold, open the run, adjust it there, and use that page's download button.
  • Downloads for each run include the original instrument file, the plate layout, and the raw fluorescence (RFU) for every well as CSV, for analysis in Excel, R or Python.
